# Arte do menu

`menu_observatory.png` é uma ilustração original criada com a ferramenta integrada
de geração de imagens. O arquivo está incluído no projeto; o jogo não usa rede
nem serviços de geração durante a execução. Títulos, botões e animações são
renderizados separadamente pelo Tkinter para preservar legibilidade e interação.

## Prompt usado

Use case: stylized-concept. Asset type: original background illustration for the
main menu of ECOS, a fast knowledge-quiz dungeon crawler. Primary request: a
premium hand-painted cinematic game environment, not a screenshot or UI mockup.
Scene: a vast subterranean research archive with brutalist dark concrete corridors
branching in several directions, luminous cyan circuit paths embedded in the floor
and a single beautiful central floating geometric data core in an architectural
ring. The environment suggests an explorable maze of knowledge, technological and
mysterious rather than medieval fantasy. No people, monsters, weapons, skulls or
magical runes. Style: polished stylized 3D concept painting, strong graphic shapes,
painterly atmospheric haze, crisp silhouette, restrained fine details, dramatic
perspective. Composition: tall portrait 2:3, for left half of a desktop game menu.
Main circular core and architectural focal point in the middle lower half, upper
third and bottom edge dark and relatively quiet to allow separately rendered
interface typography. Lighting: near-black navy and deep petroleum teal,
controlled electric cyan accents, tiny warm amber lights, subtle reflections on
the floor. Rich depth and recognizable architecture, luminous but not overexposed.
Constraints: image only, absolutely no letters, words, numbers, logos, UI panels or
buttons. Original artwork; do not imitate an existing game cover. Opaque background.
