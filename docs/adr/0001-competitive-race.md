# Competitive race instead of cooperative expedition

The crawler was cooperative: one shared clock, shared lives and combo, players alternating answers and scoring individually. We changed it to a free-for-all race in which each player moves one Room per Turn through the same Dungeon, holds their own Map, Lives and Room states, and the first to clear the Exit wins. Score, combo, speed bonus and the global clock were removed, because a points tally would contradict the win condition and a running clock would charge each player for the others' turns.

## Consequences

- Wrong answers are punished by Tier (easy: lose a Life, medium: lose the next Turn, hard: Retreat), so a missed easy Question hurts most.
- Players can affect each other through held Buffs (Hex, Swap); the cooperative "team" no longer exists.
- Online multiplayer, where players could have different Dungeons, is left for later.
